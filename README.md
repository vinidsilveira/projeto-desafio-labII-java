Desafio II – Laboratório II | Análise e Desenvolvimento de Sistemas (ADS)

Projeto desenvolvido como parte do Desafio II – Laboratório II do curso de Análise e Desenvolvimento de Sistemas (ADS), com foco na aplicação prática de estruturas de dados, recursão e lógica de programação, utilizando a linguagem Java.

O desafio é dividido em quatro etapas, cada uma abordando conceitos fundamentais da ciência da computação de forma incremental.

Objetivo do Projeto

Consolidar o aprendizado sobre:

Recursão

Pesquisa e ordenação

Estruturas de dados estáticas

Estruturas de dados dinâmicas

Pensamento lógico e resolução de problemas

O projeto foi desenvolvido em Java, com execução via console, utilizando um projeto Eclipse puro.

Estrutura do Desafio
Etapa 1 – Labirinto Recursivo

Implementação de um algoritmo recursivo para resolução de um labirinto, explorando caminhos possíveis até encontrar a saída.

Conceitos trabalhados:

Recursão

Backtracking

Controle de fluxo

Etapa 2 – Pesquisa e Ordenação

Desenvolvimento de algoritmos de pesquisa e ordenação aplicados sobre estruturas de dados lineares.

Conceitos trabalhados:

Pesquisa sequencial

Algoritmos de ordenação

Manipulação de vetores

Etapa 3 – Listas Estáticas e Recursão

Aplicação de métodos recursivos sobre listas estáticas (arrays), incluindo operações de inserção, remoção e processamento de dados.

Conceitos trabalhados:

Estruturas estáticas

Recursão aplicada a coleções

Organização de dados

Etapa 4 – Estruturas Dinâmicas (Listas Encadeadas)

Implementação de listas encadeadas, com manipulação dinâmica de nós e execução das operações básicas da estrutura.

Conceitos trabalhados:

Estruturas dinâmicas

Referências e encadeamento

Listas encadeadas

Tecnologias Utilizadas

Java

Eclipse IDE

Execução via console

Programação Orientada a Objetos

Estruturas de Dados

Como Executar o Projeto

Clonar o repositório para a máquina local

Abrir o Eclipse IDE

Selecionar File > Open Projects from File System

Escolher a pasta do projeto clonado

Executar as classes principais de cada etapa pelo console do Eclipse
