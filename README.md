\# Desafio II – Laboratório II | Análise e Desenvolvimento de Sistemas (ADS)



Projeto desenvolvido como parte do \*\*Desafio II\*\* do curso de \*\*Análise e Desenvolvimento de Sistemas (ADS)\*\*, com foco em \*\*estruturas de dados, recursão e lógica de programação em Java\*\*.



O desafio é dividido em \*\*quatro etapas práticas\*\*, cada uma abordando conceitos fundamentais da ciência da computação, aplicados de forma incremental.



---



\## Objetivo do Projeto



Consolidar o aprendizado sobre:

\- Recursão

\- Pesquisa e ordenação

\- Estruturas de dados estáticas

\- Estruturas de dados dinâmicas

\- Pensamento lógico e resolução de problemas



O projeto foi desenvolvido em \*\*Java\*\*, com execução via \*\*console\*\*, utilizando um projeto \*\*Eclipse puro\*\*.



---



\## Estrutura do Desafio



\### Etapa 1 – Labirinto Recursivo

Implementação de um algoritmo recursivo para resolução de um labirinto, explorando caminhos possíveis até encontrar a saída.



Conceitos trabalhados:

\- Recursão

\- Backtracking

\- Controle de fluxo



---



\### Etapa 2 – Pesquisa e Ordenação

Desenvolvimento de algoritmos de pesquisa e ordenação aplicados sobre estruturas de dados lineares.



Conceitos trabalhados:

\- Pesquisa sequencial

\- Ordenação

\- Manipulação de vetores



---



\### Etapa 3 – Listas Estáticas e Recursão

Aplicação de recursão sobre listas estáticas (arrays), incluindo operações de inserção, remoção e processamento de dados.



Conceitos trabalhados:

\- Estruturas estáticas

\- Recursão aplicada a coleções

\- Organização de dados



---



\### Etapa 4 – Estruturas Dinâmicas (Listas Encadeadas)

Implementação de listas encadeadas, com manipulação dinâmica de nós e operações fundamentais.



Conceitos trabalhados:

\- Estruturas dinâmicas

\- Referências e encadeamento

\- Listas encadeadas



---
